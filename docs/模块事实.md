# 角色公共模块 模块事实

## 职责

角色公共模块，负责角色树、角色状态、权限点和角色权限绑定管理。

## 数据表

- `role_roles`
- `role_permissions`
- `role_role_permissions`

## API

- `GET /api/role/hello`：模块探活
- `POST /api/role/create`：创建角色
- `GET /api/role/list`：角色列表
- `GET /api/role/detail`：角色详情
- `PUT /api/role/update`：更新角色
- `POST /api/role/enable`：启用角色
- `POST /api/role/disable`：禁用角色
- `POST /api/role/delete`：删除角色
- `GET /api/role/children-tree`：查子树
- `POST /api/role/permission-create`：创建权限点
- `GET /api/role/permission-list`：权限点列表
- `PUT /api/role/assign-permissions`：分配角色权限
- `POST /api/role/check-permission`：检查权限
- `POST /api/role/admin/ping`：管理后台探活
- `POST /_internal/method-call/role`：内部方法调用
- `POST /_internal/scheduled-trigger/role`：内部触发定时任务
- `POST /_internal/selftest/role`：废弃自测入口

## 实时事件

用户前端事件：

- 当前模块没有自有用户前端推送事件。

后台提醒事件：

- 当前模块没有自有后台实时提醒事件。

## 测试资产

- `tests/data.yaml` 声明本模块测试涉及的数据表、种子、清理和快照范围。
- 每个 `api-docs.json.apis[].endpoint_key` 都应有对应 `tests/*.test.json`。
- 新增、删除或修改接口时，必须同时更新 `api-docs.json`、测试文件和必要的数据种子。
